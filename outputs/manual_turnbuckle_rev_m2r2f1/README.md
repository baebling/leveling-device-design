# M2R2F1 — 체결 검토 수정본

프로파일 접합부의 제조사 도면을 대조하고 볼트·T너트·공구 접근을 추가 검토했다. **검토용 CAD이며 하중 지지능력/실물 체결 강도 승인본은 아니다.** M2R2의 가정 형상과 절단표를 아래 내용으로 대체한다.

- 일반 장착 볼트는 **M8×15 48개 / M5×16 24개**, 모두 일반 육각렌치 머리로 통일했다. 동봉 전용 M4와 턴버클 M12 나사는 별도 유지한다.
- M5 와셔는 **DIN433 5.3×9×1** 24개로 변경했다. T너트는 HNTT8-8 / HNTT8-5.
- 실제 브래킷40×40×30, 두께6 mm를 반영했다. 기존35 mm 가정으로 놓친 간섭을 해결하기 위해 뒤 가로재를20 mm 이동했다.
- **4080 앞 세로재 두 개의 절단 길이는450 mm**다. 기존470 mm로 주문하지 않는다. 외곽700×700×344 mm 유지.
- M5 체결 시 **지지대 동봉 M4 클램프 나사를 잠시 제거한 뒤 재조립**한다. 설치 상태 그대로는 렌치 경로가 막힌다.

## 검증 결과

264개 구성요소 / 전체354솔리드. 대표9자세 부품 교차 없음. 대표3자세에서 각84개 직선 렌치 삽입 경로를 검사했으며, 위 조립 순서 적용 후 방해 없음. 설치 상태의 M4 방해12건/자세는 JSON에 별도로 보존했다. STEP3개 재수입 유효, 최대 부피차0.000004 mm³ 미만. 169자세 길이261.379~296.532 mm, 최소 내부 나사물림19.734 mm.

M5/M8 장착 볼트 모두 슬롯 돌출9 mm, 공칭 나사 겹침6.5 mm, 바닥 여유3.5 mm. 지지대 받침은 슬롯 양쪽 각2 mm로 좁으며, 접촉압·국부 휨·미끄럼·체결 토크는 별도 확인이 필요하다. 나사 끝 불완전부를 제외한 유효 물림까지 보증한 값이 아니다.

CAD 단면의 일부 테이퍼·필릿, 칼라 전용 나사와 렌치 손잡이의 회전 범위는 생략했다. 제조사 대응 계열의 슬롯/너트 조합을 사용하며 실제 공차·하중 정격을 추정으로 확정하지 않았다. 기존 STB 압축 정격·기계 스톱·카트 연결부 미완료 상태 유지.

## 재생성

CadQuery2.8 / VTK9.6.2 환경에서 `scripts/build_manual_turnbuckle_rev_m2r2f1.py`; 단면 검사 `calculations/manual_m2r2f1_fastening.py`; 패키지 검사 `scripts/package_manual_turnbuckle_rev_m2r2f1.py`.

이번 환경에서는 CAD 결과 기록 후 프로세스 종료코드1 문제가 기존처럼 재현되었다. CAD 내부 검사 결과와 별개이며, 이 실행 자체가 정상 종료했다고 주장하지 않는다. 표준 Python의 체결 단면 계산과 작성 산출물 무결성 검사는 정상 종료했다.
