# Manual 3-RPS Rev M2R1 — CAD 검토 패키지
2026-09-05 | PRELIMINARY — NOT APPROVED FOR FABRICATION

## 먼저 열 파일
- `step/M2R1_NEUTRAL_REVIEW.step`: 색상과 부품 이름을 가진 전체 조립체. Fusion에서 업로드/열기 가능. F3D 원본은 생성하지 않았다.
- `step/M2R1_P3_R3_REVIEW.step`, `step/M2R1_PM3_RM3_REVIEW.step`: 복합 기울기 검토.
- `step/M2R1_UPPER_JOINT_REVIEW.step`: 한 축 상부 연결부.
- `step/M2R1_UPPER_JOINT_EXPLODED_REVIEW.step`: 상부 연결부 분해 표시. 분해 오프셋은 제작 치수가 아니다.
- `renders/NEUTRAL.png`, `renders/STRUCTURE_EXPOSED.png`, `renders/UPPER_JOINT_SECTION.png`, `renders/UPPER_JOINT_EXPLODED.png`.

## 이번 CAD에서 바뀐 것
기존 Rev M2는 보존했다. 수정본은 `cad/manual_turnbuckle_rev_m2r1.py`다.
- 실제 상부 포크의 큰 핀 구멍을 표현하고 독립 부시 6개를 넣었다.
- 구면 로드엔드 외륜 하우징과 상부 핀을 따르는 내륜을 분리했다.
- 내륜 양옆 지지용 스페이서 6개를 추가했다. 기존 BOM에 없던 항목이므로 견적/조립 목록에 반영해야 한다.
- 핀 머리·와셔·잠금너트와 평활 몸통 길이를 모델링했다. 기존 M12x65 표기를 임시 M12x80 검토안으로 변경했다.
- 기존 상하 프레임/지지점/링크 길이 계산은 유지하고 은색 프레임·검은 연결부·A1/A2/A3 라벨을 반영했다.
- 프로파일을 제조사 상세 단면으로 바꾸거나 생성형 이미지처럼 링크 위치를 바꾸지 않았다.

## 검증
수정본 112개 이름 있는 구성요소, 169개 솔리드. 9자세에서 모든 서로 다른 구성요소 쌍을 AABB로 추린 뒤 OpenCascade 교차체적으로 검사했다.
현재 기록은 `M2R1_CAD_AUDIT.json`을 따른다. 부품 간 판정 임계 교차체적은 0.01 mm³다.
복합 링크 내부의 중첩 나사 표현은 별도 부품 간 검사에 포함되지 않는다. 나사는 원통 외형으로 표현했고 실제 나선 공차를 검증하지 않았다.
중립 STEP를 재수입해 전체/개별 솔리드 유효성과 원본 부피 일치를 확인했다.
새 구면 형상의 초기 STEP 재수입 오류를 발견해 회전 단면으로 다시 작성한 후 9자세와 재수입을 다시 검사했다.
이 결과는 정격/내구/현장 안전/실제 공급품 조립성 검증이 아니다.

## 가정과 미확정 항목 — 발주 전 필수
- 포크 간격 22.4, 보어 20.1, 부시 OD19.98/ID12.1, 몸통 길이 11, 플랜지 OD26/두께1.5 mm는 공칭 조립 검토값이다. 실제 공급 보어/공차에 맞춰야 한다.
- 구면 내륜 OD24/폭16, 하우징 OD30/폭12/구면 시트OD24.2는 공급자 STEP가 없는 근사 외형이다. 구면 좌면/베어링 정격을 제작 지정한 것이 아니다.
- 내륜 스페이서 두께는 `(실제 포크 간격 - 실제 내륜 폭)/2`. 현재 3.2 mm는 중립 공칭값이다. 실제 편차는 측정 후 심/스페이서로 맞춰야 하며 고정 3.2 mm 6개를 바로 가공하면 안 된다.
- 임시 M12x80 핀의 평활 몸통 50 mm를 가정했다. 마지막 부시 끝 대비 평활부 여유는 0.6 mm에 불과하므로 공급 공차/와셔/목부분을 확인하기 전 확정품이 아니다. 하중 접촉부에 나사산이 걸리면 다시 선정한다.
- 재질 색은 구분용이며 부시 재질/윤활/압입/빠짐방지의 최종 선정은 아니다. 부시 플랜지는 외측에 있고 핀 머리·와셔·너트로 포획하는 개념이다.
- STB 압축 사용, 정확 LH 로드엔드/너트, 하부 핀 리테이너, 프레임 체결품 상세, 독립 기계 스톱, 실제 카트 리시버·하부 고정은 아직 열려 있다.
- 총 이동질량/CG 및 하중편심은 실측 후 확인한다. 수동 ±3°와 10 kg 시험하중이 목표이며 실물시험 미실시다.

## 부품 변경표 — 주문서 아님
| 기존 항목 | 수정본 |

| M07 부시 6개, 추상 표시 | 독립 플랜지 부시 6개, 공차/재질 미확정 |

| 청색 어댑터 표현 | 기본 금속 표면 + 축 식별 라벨 6개 |

구매/제작 승인은 false다. 제조용 DXF/공차도는 새로 발행하지 않았다.

## 재생성
Python 3.12, CadQuery 2.8, VTK 9.6 환경에서 프로젝트 루트를 PYTHONPATH에 포함하고 `scripts/build_manual_turnbuckle_rev_m2r1.py`를 실행한다.
이 프로젝트의 `vendor/python`에 의존성이 있다. `MPLCONFIGDIR`/`XDG_CACHE_HOME`은 프로젝트 내부 캐시 폴더로 지정한다.
