# 수평유지장치 최종 맞춤가공 STEP 패키지

용도: 감독하 실내 자중 시연용 PoC. 카트·적재물·사람 탑승용이 아니다.

## 실제 업로드 파일과 수량

`01_UPLOAD_PRIMARY` 폴더의 STEP 4종만 견적 사이트에 업로드한다.

| 파일 | 재질 | 완성 수량 | 핵심 가공 |
|---|---|---:|---|
| A1 하부 어댑터 | A6061-T6 또는 A6061P-T651 | 1 | 120×70×8, Ø9 관통 2개, M8×1.25 관통탭 2개 |
| A2 하부 어댑터 | A6061-T6 또는 A6061P-T651 | 1 | 120×70×8, Ø9 관통 2개, M8×1.25 관통탭 2개 |
| A3 하부 어댑터 | A6061-T6 또는 A6061P-T651 | 1 | 120×70×8, Ø9 관통 2개, M8×1.25 관통탭 2개 |
| PHS6 직접체결 상부판 | A6061-T6 또는 A6061P-T651 | **3** | 60×30×9, Ø6.6 관통 3개, 중앙 상면 Ø11×깊이 4.5 카운터보어 |

총 완성품은 6개이고, 서로 다른 STEP 형상은 4종이다.

## 하부판의 중요한 탭 지시

견적 사이트 호환성을 위해 `01_UPLOAD_PRIMARY`의 A1~A3 STEP은 탭 위치를 Ø6.8 밑구멍으로 단순 표시했다. **Ø6.8 일반 관통홀로 납품받으면 안 된다.** 해당 위치는 반드시 Ø6.8 드릴 후 **M8×1.25 관통 탭**으로 완성한다. 나사산 형상을 확인해야 할 때만 `02_REFERENCE_THREADED_LOWER`의 상세 STEP을 사용한다. 좌표와 가공지시는 `FABRICATION_REQUIREMENTS.csv`가 우선한다.

## 상부판의 중요한 방향

상부판은 세 축에 같은 부품을 사용한다. 카운터보어가 보이는 면이 `TOP`이며 3030 프로파일 하부면과 접한다. 중앙에는 MISUMI CBS6-12를 사용해 PHS6를 먼저 체결한 뒤 판을 프로파일에 조립한다. 키홀판, U볼트, 기존 일체형 포켓 브래킷은 발주하지 않는다.

## 공통 가공 조건

- 일반공차: 별도 지정이 없는 치수 ±0.2 mm
- 모든 모서리와 구멍 디버링, 날카로운 모서리 가볍게 제거
- 열처리·도금·아노다이징 없음
- STEP과 CSV가 충돌하면 견적 확정 전 문의하고 임의 변경하지 않는다.

## 포함하지 않은 구형 파일

- `UP_A1/A2/A3_PHS6_POCKET_BRACKET.step`: 폐기된 일체형 머시닝안
- split-keyhole mount/support STEP: 폐기된 2분할 검토안
- `UPPER_PHS6_DIRECT_MOUNT_THREE_AXIS_REVIEW.step`: 조립 검토용이며 가공 발주 대상이 아님
