## 하부판의 중요한 탭 지시

견적 사이트 호환성을 위해 `01_UPLOAD_PRIMARY`의 A1~A3 STEP은 탭 위치를 Ø6.8 밑구멍으로 단순 표시했다. **Ø6.8 일반 관통홀로 납품받으면 안 된다.** 해당 위치는 반드시 Ø6.8 드릴 후 **M8×1.25 관통 탭**으로 완성한다. 나사산 형상을 확인해야 할 때만 `02_REFERENCE_THREADED_LOWER`의 상세 STEP을 사용한다. 좌표와 가공지시는 `FABRICATION_REQUIREMENTS.csv`가 우선한다.

## 상부판의 중요한 방향

상부판은 세 축에 같은 부품을 사용한다. 카운터보어가 보이는 면이 `TOP`이며 3030 프로파일 하부면과 접한다. 중앙에는 MISUMI CBS6-12를 사용해 PHS6를 먼저 체결한 뒤 판을 프로파일에 조립한다. 키홀판, U볼트, 기존 일체형 포켓 브래킷은 발주하지 않는다.

## 10월 7일 기성품 조립 수정

### 상부 핀 (세 축 동일)

핀은 HCDGH6-35가 아니라 **HCDGH6-40**을 사용한다. 머리부터 E링 방향으로 `와셔4 → 액추에이터 아이20 → 와셔1.5 → PHS6 내륜9 → 와셔4 → 얇은심 → 유격 → 동봉 E링` 순서다. 명목 얇은심은 0.5 mm 두 장=1.0 mm로, 유격은 명목 0.5 mm이다. 실제 부품을 끼운 뒤 0.1/0.5 mm 심으로 **0.2~0.5 mm의 축방향 자유 유격**을 남긴다. 구면 내륜을 강제로 죄거나 E링을 억지로 넣지 않는다. 제공 STEP/렌더에서 액추에이터 아이와 실제 E링 세부 형상은 생략/단순화되어 있으므로 이 적층 순서를 따른다. E링이 홈에 완전히 앉는지 육안으로 확인한다.

헤드 쪽 적층은 그대로여서 아이–볼 중심 편심 16 mm와 기존 판 좌표는 바뀌지 않는다. 핀의 길이 변경은 공차 조립 문제를 줄이기 위한 것이며 핀의 굽힘강도 향상이나 750 N 하중 검증을 의미하지 않는다. CBS6-12의 PHS6 공칭 나사 물림은 잔여 판 두께 `9−4.5=4.5`를 빼서 `12−4.5=7.5 mm`이다.

### HWT905 고정부 (상·하부 각 1세트)

센서판은 기성 `ENBT-100-100-5` PVC를 두 장 사용한다. **금속판이 아니며 새 금속 타공은 없다.** 좌표는 [플라스틱 타공 안내](../20261007_bom_three_issue_correction/HWT905_플라스틱판_타공조립.svg)를 따른다. 센서 3홀은 공급사 도면의 47.9/28.7 mm 피치를 기준으로 하되 실물에 대어 위치를 옮겨 그린 뒤 PVC만 뚫는다.

- 상부판: 센서 Ø4.2 관통 3개, 프레임 Ø6.6 관통 2개. M6×25 2개 + WSSB10-6-1.5 머리 밑 2개 + WSSB10-6-5 간격재 4개 + E-SPN306 너트 2개. 간격재는 각 체결점 5 mm 두 장=10 mm로 쌓는다.
- 하부판: 센서 Ø4.2 관통 3개, 프레임 Ø9 관통 2개. M8×25 2개 + 기존 M8 평와셔 2개 + WSSB12-8-5 간격재 4개 + 기존 하부 4040용 M8 슬롯너트 2개. 하부에는 3030용 M6 너트를 넣지 않는다.
- 센서 고정: 기존 M4×25 더블샘스 볼트 3개와 M4 너트 3개를 각 판에 사용한다. 볼트 머리는 PVC 아래, 너트는 센서의 장착 귀 위다. 튀어나온 나사는 센서 몸체 옆의 빈 공간에 놓이고 금속 나사를 자르지 않는다. 플라스틱이 휘거나 귀가 손상되도록 과도하게 조이지 않는다.
- 위치: 상부/하부 뒤쪽 횡보의 상면. 판 중심은 `(X,Y)=(0,−295 mm)`, 두 프레임 체결홀은 `(±40,−330 mm)`이다. 100 mm 판과 10 mm 간격재로 M4 볼트 머리 공간을 확보했다. 첫 조립 시 볼트가 슬롯 바닥에 닿거나 판이 흔들리는지 확인하고, 센서 케이블에는 움직임 여유와 인장 완화를 준다.
- 핀 및 센서 고정부는 Z 0/25/50 mm, pitch/roll −3/0/+3°의 27개 표본 자세에서 검사했다. 케이블, 공구 접근, 실물 공차, 통전 성능까지 검증했다는 뜻은 아니다.
