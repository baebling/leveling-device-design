# Rev E 상부 핀축 정렬 보정 CAD — 2026-10-02

상태: `PURCHASE_RELEASE=FALSE`, `FABRICATION_RELEASE=FALSE`. 본 STEP와 그림은 자중 시연용 상부 모듈의 **형상 검토본**이며 제작도면이 아니다.

이 패키지는 공급자 `LM4075OE-1075-100mm.stp`를 사용하고, 액추에이터 전면 아이의 Ø6 축을 세계좌표 고정 하부 힌지 축에 맞춘 자세식으로 다시 생성했다. 2026-09-30 폴더의 구형 STEP/JSON은 상부 실제 핀을 누락한 상태에서 상부 두 구멍축이 어긋났으므로 사용하지 않는다.

검증 범위: 27개 표본자세의 공급자 액추에이터 형상·간략 LMB-10/PHS6 외형과 기존 프레임 간섭 스크리닝, 자세식 중심선 정렬. 상세 조건과 수치는 [연속검증 기록](../20261002_reve_followthrough/연속검증_중간기록.md)에 있다.

아직 **모델에 없는 것**: 실제 상부 Ø6 핀·M5 너트/와셔, F07 스프링너트의 실형상과 프로파일 홈 바닥, 독립 양방향 기계 스토퍼, 움직이는 케이블과 장력완화, 실제 공차, 전장함. CAD 메타데이터는 F07 몸체 5 mm와 F11 끝단의 명목 1 mm 돌출을 기록하지만, 홈 바닥/불완전 나사산을 간섭 검사한 것은 아니다. 따라서 JSON에 겹침 0이 나와도 전체 조립 가능·안전·구매 승인을 뜻하지 않는다. [한국미스미 `CLBGHN6-31`](https://kr.misumi-ec.com/vona2/detail/110300095930/?HissuCode=CLBGHN6-31)은 치수/주문 후보이지 이 STEP에 이미 검증된 체결품이 아니다.
