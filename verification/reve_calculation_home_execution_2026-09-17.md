# Rev E 계산·HOME 해석 실행 결과 — 2026-09-17

## 판정 — 개념만 승인, 구매·제작·통전·PoC 인수 미승인

기존 Rev E/Rev D 유지형상에 대한 승인 운전영역 계산은 예비 통과했다. 조밀 시작자세 1,859개에서 6개 순차 HOME 순서는 모두 탈락했고, 1 mm 교대수축 `A3 → A2 → A1`만 시작자세 경로 자체를 공통 통과했다. 최악 중간상태에서 교대 위상을 잊고 A3부터 다시 시작하면 5°를 초과하므로 일반적인 무상태 재시작은 불가하다. 후속 계산에서 선택 경로의 216,951개 중간상태는 같은 전원 세션에서 다음 위상을 보존하면 원래 접미 경로와 모두 일치했다.

따라서 현재 결과는 `PRELIMINARY_LIVE_SESSION_RESUME_CLOSED_POWER_LOSS_BLOCKED`이며 구매·제작·통전 릴리스 근거가 아니다. HOME 중단 후 재개는 같은 전원 세션에서 엔코더 카운트가 연속이고 활성축·단계목표·다음 위상이 RAM에 유지될 때만 허용한다. 증분형 엔코더와 실제 이동/NVM 기록을 원자화할 수 없으므로 MCU reset·제어전원 상실·E-stop 이후에는 `HOME_START_UNVERIFIED`로 자동 HOME과 자동 재개를 거부한다.

> 본 결과는 카트·적재물·사람이 없는 자중 PoC 전용이다. 제작 승인, 사람 탑승, 현장 안전 또는 인증 적합성을 뜻하지 않는다.

| HOME 축길이 스텝 | 1 mm 이하 | 승인 요구 |

| 조인트 편각 한계 | 기존 모델 8° / LDK PHS 6 데이터시트 13° | PHS 공개 데이터시트 확보, 최종 CAD 형상 미반영 |
| 형상 | 기존 ProfileRadialRevD/RevE actual-vendor 모델 | LDK PHS 6·LMB-10 변경 전 |

세 길이에서 `x, y, lift, pitch, roll, yaw`를 푸는 6변수 Newton 전진기구학을 사용했다. 잔차는 액추에이터 길이식 3개와 R축 접선 구속식 3개이며, 경로에서는 직전 해를 다음 해의 초기값으로 사용했다. 조밀 격자와 경로 표본은 유한 수치 스크리닝이며 연속공간의 수학적 증명이 아니다.

HOME의 명목 205 mm 하한은 정상운전 소프트웨어창 210~280 mm 밖에 있다. 따라서 HOME은 정상 자세명령과 분리된 특수 저속 상태로만 하한 방향 이동을 허용하고, 종단 확인 직후 210 mm 이상으로 탈출하기 전에는 LIFT/LEVEL/JOG 정상명령을 금지해야 한다. 실제 예외창은 실측 `L_low_switch`와 종단 구분 신호가 확정된 뒤 코드 요구로 동결한다.

## CAD 간섭 확인 범위

CadQuery 실형상 교차검사는 다음 **대표 4자세 spot-check에 한해서만** 최대 교차부피 0 mm³였다.

1. 선택 경로 최대 기울기 자세
2. 선택 경로 최대 조인트 편각 자세
3. 무상태 재시작 실패 자세
4. 세 축 명목 205 mm 동일길이 종단자세

이 모델의 “vendor STEP”은 LM4075OE 액추에이터 STEP만 뜻한다. LDK PHS 6와 LMB-10의 상세치수는 확보했지만 아직 현재 CAD 형상에 교체 반영되지 않았다. 216,951개 선택 경로 상태 전체의 정확 CAD 교차검사도 아니고 독립 스토퍼 릴리스형을 반영한 검사도 아니다. 따라서 `FULL_PATH_CAD_COLLISION_AUDITED=FALSE`를 유지한다.

## 위상 보존 재개와 정상창 복귀

선택 교대경로의 모든 216,951개 길이상태에서 저장된 `next_phase_index`로 재생성한 경로가 원래 경로의 접미열과 일치했다. 실패상태는 0개다. 이는 같은 전원 세션의 결정론적 경로 재개 증거이며, 전원상실 뒤 실제 위치 복구 증거는 아니다.

명목 동일하한 `(205,205,205) mm`에서 세 축이 모두 210 mm가 될 때까지 1 mm 교대신장하는 여섯 순환순서도 모두 통과했다. 제어 분기를 줄이기 위해 HOME 수축과 같은 `A3→A2→A1`을 선택한다. 선택 경로는 16개 길이상태, 최대 기울기 0.232856477°, 기존 조인트 편각 0.208048630°였다. 실제 하한 리미트 길이가 축별로 다를 수 있으므로 입고 후 세 축 작동점을 측정해 오프셋만 저장한다.

## HOME 준비자세와 JOG 선분

직접 HOME을 임의 중간자세에서 시작하지 않고 `HOME_PARK=(Z0,pitch0,roll0)`을 거치도록 제어정책을 제한했다. 조밀 1,859자세 각각에서 HOME_PARK로 가는 선분 1,859개와 조밀격자 양의 방향 인접 JOG 선분 5,122개를 Z 1 mm·각도 0.1° 이하로 표본화했다.

총 89,707개 표본의 핀 길이는 210.771741~276.937115 mm, 최대 플랫폼 기울기 4.241671°, 기존 모델 PHS 편각 4.096369°로 예비 통과했다. 이는 정의된 HOME 준비정책과 조밀 인접 JOG의 유한 표본만을 뜻한다. 임의의 두 자세 간 직접명령, 연속영역 증명과 최종형상 CAD 충돌검사는 아니다.

## 남은 차단조건과 다음 실행순서

1. 공개 상세자료의 전류·듀티·엔코더·리미트·LMB-10·PHS 6 치수를 설계 입력으로 사용한다. 입고 후 50 mm 이동과 양단 저속 JOG로 counts/mm와 리미트 작동점만 보정한다.
2. 같은 전원 세션의 위상 보존 재개와 명목 205→210 mm 정상창 복귀는 예비 동결했다. 전원상실·MCU reset·E-stop 이후 자동 재개를 금지하고 `HOME_START_UNVERIFIED`로 보내는 상태기를 구현한다.
3. 현재 HOME 준비·인접 JOG 유한표본은 통과했다. 임의 직접명령은 금지하고 준비자세 경유 정책을 코드에 구현한 뒤, 실측 축별 오프셋과 counts/mm를 저장한다.
4. LDK PHS 6·LMB-10와 독립 기계식 스토퍼 릴리스형을 CAD에 반영하고 조밀 격자·명령선분·HOME 전체경로를 재검사한다.
5. 위 CAD 검사와 입고 보정 절차를 반영한 뒤 펌웨어 HOME 상태기와 최종 BOM을 동결한다.

현재 게이트는 다음과 같다.

```text
CONCEPT_APPROVED = TRUE  # 개념만 승인
PURCHASE_RELEASE = FALSE
FABRICATION_RELEASE = FALSE
CONTROL_POWER_TEST_RELEASE = FALSE
MOTOR_POWER_RELEASE = FALSE
POC_ACCEPTANCE = FALSE
```
