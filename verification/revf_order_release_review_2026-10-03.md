# Rev F 발주 후보 비판 검토 결과

## 판정

맞춤 상부 포켓 브래킷 3개의 사용자 견적만 추가하면 발주 진행이 가능한 수준으로 정리했다. 나머지 관절 부품과 전장 부품은 정확 모델·수량·연결 역할을 BOM에 반영했다. 다만 이 판정은 감독하 실내 자중 PoC의 **결과물 제작 가능성** 기준이며, 인증·사람 탑승·현장 안전을 승인하지 않는다.

## 해결한 주요 충돌

| 이전 문제 | 최종 처리 |
|---|---|
| 상부 관절 핀·와셔·PHS6 포획부 미선정 | HCDGH6-35 + WSSB10-6-4 + WSSB10-6-1.5 + CBS6-12로 확정 |
| 상부 3030 부품이 판매처/슬롯 계열과 혼재 | 한국미스미 E-DNF3030, E-SPN306, E-DCBK3025, CB6 계열로 통일 |
| G9EA와 별도 릴레이가 굵은 전선·러그·압착공구를 요구 | Finder 22.32.0.024.4320 한 대의 2NO로 주전원+자기유지 처리 |
| 31.3 A 전원과 25 A 접촉기의 정격 불일치 | 모터계통 전단에 20 A 주퓨즈를 두어 접촉기 경로를 20 A로 제한 |
| 작은 함체와 1 m DIN 레일 절단 | BC-AGP-507025 + 5070P, MRB-300 3개로 변경 |
| DMC 전용 프로토콜을 Modbus 게이트웨이에 넣을 위험 | DMC는 Portenta J5 직결; ZMEC는 Modbus HWT905 두 대 전용으로 분리 |
| Portenta J7 통신 사용 가능성 | J7은 온도 프로브 단자이므로 사용하지 않고 J5만 통신에 사용 |
| 전원 복귀 후 자동 재기동 | E-stop NC + START NO + Finder 보조 NO 자기유지로 수동 START 필요 |

## 공학적 적합성 확인

- LM4075OE-1075의 공개 24 V 부하전류 1.5 A/축에 대해 DMC-200 8 A급은 정상운전 여유가 있다. 확인되지 않은 피크전류는 DMC 6 A 초기 제한, 축별10 A 퓨즈, 주20 A 퓨즈로 단계적으로 제한했다.
- Finder 접촉기의 공개 DC-1 정격 30 VDC/25 A보다 주퓨즈20 A가 낮다. 모터 자체가 아니라 세 DMC의 DC 입력을 차단하므로 PoC의 저빈도 수동 개폐에 적합한 방향이다.
- RSP-750-24는 31.3 A로 과대지만, 사용자가 채택한 부품을 유지하면서 하류를 20 A로 제한하므로 배선·접촉기 정격을 전원 최대치에 맞춰 과대화할 필요가 없다.
- HWT905-485는 Modbus RTU 제품이며 ID 변경이 가능하므로 두 대를 한 버스에 사용할 수 있다. ZMEC는 이 센서 버스만 TCP로 변환한다.
- DMC-200 문서에는 ID 설정, 위치·속도 제어 전류 제한, 엔코더 분해능 설정이 있다. 3축은 한 대씩 ID를 바꾼 후 같은 버스에 연결한다.
- 기계적으로 정상 명령 범위는 완전 수축점에서15 mm 떨어진 기준점을 사용한다. +50 mm 명령은 물리 신장65 mm라 100 mm 스트로크 끝까지35 mm가 남는다. 실제 간섭이 보이면 명령 상한을+35 mm로 낮춰 물리 신장50 mm까지만 사용한다.

## 발주 전에 사람이 해야 할 3개 확인

1. 상부 포켓 브래킷 STEP 3개를 meviy 등에 업로드해 공급가·VAT·납기를 BOM에 더한다.
2. 각 사이트 결제 화면에서 동적 가격·재고·배송일을 갱신한다. BOM 숫자는 2026-10-03 기준 후보 공급가다.
3. 모터뱅크 결제 옵션에서 액추에이터가 24 V·100 mm·5 V 엔코더형인지 다시 확인한다.

## 수령 후 조정으로 넘긴 항목

- LMB-10 핀/R클립 실제 동봉 여부.
- HCDGH6-35 적층의 실제 0.5 mm 여유. 너무 타이트하면 WSSB10-6-1.5를 빼고 저속 자중 시연으로 제한한다.
- HWT905 Modbus ID 0x50/0x51 설정, DMC ID 1/2/3 설정.
- 액추에이터 방향, 엔코더 증가방향, 실제 기동전류와 내부 리미트 역방향 탈출은 한 축씩 통전하여 확인한다.

완벽한 양산 조립성 대신, 추가 금속가공 없이 조립 결과물을 만드는 기준으로 종료한다.
