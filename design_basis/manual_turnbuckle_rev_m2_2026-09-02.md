# Manual 3-RPS Rev M2 - 시판 턴버클 단순화 설계 기준

> 2026-09-05 재활성화/정정: 최신 검토는 `manual_revm2_minimal_completion_2026-09-05.md`를 따른다. 아래 'SJN 잠금너트'는 STB 동봉 잠금너트를 뜻하는 부정확한 명칭이며 SJN 자체는 중앙 joint nut다. 기존 상부 부시 모델/끼움 검사는 실부품 검증을 대체하지 않는다. 기존 통과 기록은 해당 단순화 모델 범위에 한정한다.

작성일: 2026-09-02  
상태: `ACTIVE_CANDIDATE`, `PURCHASE_RELEASE=FALSE`, `FABRICATION_RELEASE=FALSE`

## 1. 변경 판단

Rev M1은 자동차용 쇼바가 아니라 자체 설계한 Ø32/Ø25 텔레스코픽 수동 스트럿이었다. 그러나 축당 7개 조절홀, 정밀 리머가공, POM 가이드, 나사 플러그와 맞춤 클레비스가 필요해 사용자가 지적한 것처럼 PoC 제작성이 좋지 않았다.

Rev M2는 공통 Z 50 mm를 제외하고 사용자 핵심 요구인 pitch/roll 각각 +/-3 deg만 구현한다. 세 축은 다음 시판품 조합으로 바꾼다.

1. 하부 R 관절: `BJ762-12001` 포크 + 공급 Ø12 핀
2. 하부 링크 아이: `BJ761-12011N`
3. 길이조절: M12x36 연결너트 + `NBK STB-M12` RH/LH 턴버클
4. 상부 S 관절: `PHS12L` 좌나사 암 로드엔드
5. 상부 포크: `BJ762-20001` + ID12/OD20/L11 감속 부시 2개 + M12 핀볼트

하부는 반드시 단일 회전축 R을 유지하고 상부만 구면 S로 둔다. 양단을 모두 로드엔드로 바꾸면 X/Y/yaw 구속이 사라지므로 허용하지 않는다.

## 2. 확정 CAD 변수

| 항목 | Rev M2 값 |
|---|---:|
| 외곽 포락체 | 700 x 700 x 300 mm |
| 하부/상부 프로파일 | DNF4040 / DNF3030 |
| 지지 방위각 | 90 / 210 / 330 deg |
| 하부/상부 지지 반경 | 75 / 315 mm |
| 하부/상부 핀 중심 z | 81 / 213 mm |
| 하부/상부 스페이서 | 15 / 20 mm |
| 어댑터 평판 | A6061-T6 100 x 60 x 5 mm, 각 3장 |
| 상부 횡재 위치 | y=315, -157.5, -330 mm |
| 운동범위 | pitch/roll 각각 +/-3 deg, 공통 Z 없음 |

상부 전면 y=330 횡재는 y=315 지지 횡재와 중첩되므로 삭제했다. 상부는 측면 700 mm 2개와 640 mm 횡재 3개다.

## 3. 길이와 나사 물림

- 9자세 요구 핀 중심 길이: `262.724-284.444 mm`
- 요구 조절 span: `21.720 mm`
- 시판 조합 사용범위: `260-300 mm`
- 하한 여유: `2.724 mm`
- 상한 여유: `15.556 mm`
- 최악 자세 STB 내부 물림: `25.778 mm`
- 설계 최소 내부 물림: `18 mm = 1.5d`

STB 양쪽 스터드는 항상 같은 양만큼 빠져야 한다. 중앙 턴버클 1회전당 핀 중심거리는 `3.5 mm` 변한다. 외부 결합부는 하부 연결너트에서 STB 12 mm/BJ761 22 mm와 내부 2 mm 간극, 상부 PHS12L에서 13 mm 물림을 사용한다. STB 공급 SJN 잠금너트 2개/축을 유지하고, BJ761-연결너트 RH, 연결너트-STB RH, STB-PHS12L LH 경계에도 잠금너트를 각 1개/축 추가한다.

## 4. 제작 단순화 결과

맞춤가공품은 두 종류의 평판 각 3장, 합계 6장뿐이다. 두 평판 모두 100 x 60 x 5 mm 외형, M8 관통 2개와 중앙 관통 1개인 2D 절단품이다.

제거한 작업:

- Ø32/Ø25 튜브 절단과 21개 조절홀 정렬/리머가공
- POM 가이드링과 부싱 하우징 공차가공
- 나사 플러그와 맞춤 상·하 클레비스 가공
- 용접과 M8/M10 탭가공

남은 현장 작업:

- 프로파일 직각 절단
- 어댑터 6장 레이저/워터젯 절단
- BJ762 스터드 끝 여유를 받는 프로파일 벽 relief hole: 하부 Ø13.5 3개, 상부 Ø21.5 3개
- 표준 프로파일 브래킷 볼트 조립

## 5. 검증 결과

`scripts/verify_manual_turnbuckle_rev_m2.py`가 아래 세 단계를 두 번 반복했다.

1. 3-RPS 운동학, 길이범위, 나사 물림, M12 좌굴과 5 mm 평판 굽힘
2. 9자세 CadQuery/OpenCascade B-rep 유효성 및 비의도 교차체적
3. 포크 간격/목 폭/부시/너트 공간 단면 대체검사와 BOM-모델 수량 역검산

두 사이클은 동일했고 각 사이클의 간섭은 0건이다. 대표값은 다음과 같다.

- 보수적 M12 Euler 좌굴하중: 11.50 kN, 600 N 축설계하중 대비 19.16배
- M12 직접응력: 7.12 MPa
- 5 mm A6061-T6 평판 보수 굽힘응력: 42 MPa, 항복 대비 6.57배
- 모델 컴포넌트: 76개
- 포락체: 700 x 700 x 300 mm

### 5.1 잠금 후 자립성 추가 검증

`scripts/verify_manual_turnbuckle_rev_m2_stability.py`로 다음 검사를 두 번 반복했고 결과가 동일했다.

- pitch/roll -3~+3 deg를 0.5 deg 간격으로 조합한 169자세에서 6자유도 구속 Jacobian은 모두 rank 6이다.
- 최소 특이값은 0.4018, 최대 조건수는 4.3105다. 설계 영역에서 기구학적 특이점 징후가 없다.
- 링크 2개만 연결하면 rank 4, 세 링크의 양끝을 모두 구면조인트로 만들면 rank 3이다. 따라서 완전 조립 전이나 하부 R축을 임의 변경한 구성은 자립한다고 보면 안 된다.
- 총 지지질량 20 kg, 수평 CG 편심 150 mm, 169자세 x 72방향 = 12,168조건의 수직반력 근사검사에서 최소 반력은 2.954 N으로 양수다.
- 같은 검사에서 최대 등가 링크 축력은 306.660 N이며 600 N/다리 설계기준 대비 1.957배 여유다.
- 투영 지지삼각형의 최소 내접반경은 157.097 mm로, 가정한 CG 편심보다 7.097 mm 크다. 이 여유가 작으므로 실제 CG는 측정해야 한다.
- M12x1.75 기본 나사의 이상적 역구동 임계 마찰계수는 약 0.0513일 뿐이고 NBK가 self-lock 정격을 제시하지 않았다. 나사 마찰만 믿지 않고 STB 공급 SJN 잠금너트와 세 외부 결합부 잠금너트를 모두 체결한다.

판정은 **세 링크를 모두 연결하고 모든 잠금너트를 체결한 정지 상태에서는 중앙 지지기둥 없이 상판이 자립 가능**이다. 조립 중, 링크 한 개를 분리한 상태, 또는 하중을 올린 채 턴버클을 조정할 때는 상판 임시 받침을 사용한다.

이 판정은 상판-링크 기구와 가정된 수직하중에 대한 예비 검증이다. 실제 하부 접촉/카트 체결 다각형, 완성 질량중심, 횡방향 충격 조건이 없으므로 바닥 위 비고정 전체 장치의 외력 전도저항은 아직 검증되지 않았다. 700 mm 외곽과 150 mm 편심만 사용한 중력선의 명목 가장자리 여유는 200 mm지만 발주 승인값으로 쓰지 않는다.

잠금너트 CAD/BOM 갱신 후 프로젝트 전체 회귀시험은 `217 tests OK`로 통과했다.

## 6. 조립·조정 조건

1. 하부 프레임을 평면에 고정하거나 확실히 지지한 뒤 상판을 임시 받침 2점 이상으로 목표 높이에 둔다.
2. 세 턴버클을 모두 연결하고 같은 나사 물림량으로 중립 길이를 맞춘다.
3. 무하중 또는 별도 받침 상태에서만 턴버클을 돌린다.
4. 자세 설정 후 STB 공급 SJN 잠금너트 2개/축, `F09` BJ761-연결너트 RH, `F11` 연결너트-STB RH, `F12` STB-PHS12L LH 잠금너트를 모두 체결한다.
5. 세 링크가 모두 잠긴 것을 확인한 뒤 임시 받침을 제거한다.

## 7. 아직 닫히지 않은 게이트

1. 국내에서 정확한 `PHS12L M12x1.75 LH`를 조달하고 도면 치수를 재확인한다.
2. `F12` M12x1.75 LH 잠금너트의 정확한 국내 조달품을 확정한다.
3. ID12/OD20/L11 플랜지 부시 재고품을 특정하고 실물 BJ762-20001 포크와 맞춘다.
4. NBK는 STB를 위치조절용으로 설명하지만 압축 정격을 공개하지 않는다. 공급자 확인 또는 축당 900 N 이상 1축 proof test가 필요하다.
5. 어댑터 1세트와 프로파일 relief hole의 너트/공구 접근을 1차품으로 확인한다.
6. 완성 모듈 질량중심과 실제 하부 접촉/카트 체결 다각형을 측정해 외력 전도 검증을 닫는다.
7. 위 항목 전에는 전체 발주와 6장 일괄가공을 승인하지 않는다.
