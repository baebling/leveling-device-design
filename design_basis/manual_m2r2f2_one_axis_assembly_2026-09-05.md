# M2R2F2 한 축 상·하부 접합부 3D 조립 검토

2026-09-05. 사용자 요청에 따라 A1 한 축을 전체 장치에서 분리하고, 하부 R 관절과 상부 S 관절을 조립/분해 상태로 다시 모델링했다. 검토용이며 구매·제작 릴리스가 아니다.

## 먼저 정정할 점

모든 제품의 모든 치수를 확인한 상태는 아니다. 이번 검토에서 조립 성립에 직접 필요한 카탈로그 치수는 확인했다. 주물 필릿, 테이퍼, 나사산, 그리스 니플, 로드엔드 내부 부시, 칼라의 슬릿 같은 상세 형상은 일부 단순화 또는 생략했다. 실제 납품품 공차와 하중 정격은 실물/공급사 확인 대상이다.

## 한 축의 조립 구조

```text
하부 4080 프로파일
  └─ HNTT8-5 + DIN433 M5 와셔 + M5×16
      └─ SHAT12 두 개
          └─ Ø12×100 축
              └─ [5.9 심] - BJ761-12011N - [5.9 심], 총 0.2 유격
                  └─ DIN6334 M12×36 + STB-M12
                      └─ PHS12L
                          └─ [5.0 심] - PHS 내륜16 - [5.0 심]
                              └─ Ø12×100 축 + SHAT12 두 개
                                  └─ 상부 4080 프로파일
```

축 양 바깥에는 MCL-12-F 칼라가 지지대 외측면에 닿는다. 칼라는 축 이탈 억제용이고 지지대는 축을 클램프한다. 하부 회전은 BJ761 아이와 축 사이에서, 상부 기울기 보정은 PHS12L의 구면 내륜에서 발생한다.

## 적층 검토

두 SHAT12는 4080의 40 mm 피치 슬롯에 하나씩 놓인다. 각 지지대의 축방향 폭이14 mm이므로 안쪽 면 간격은 40−14=26 mm다.

- 하부: 5.9 + BJ761 폭14 + 5.9 =25.8 mm. 총0.2 mm, 좌우 공칭0.1 mm 유격을 남긴다.
- 상부: 5 + PHS 내륜폭16 + 5 =26 mm. 공칭 맞닿음이다. 실제 폭 공차를 측정한 후 기성 DIN988 심 조합만 바꾼다.
- 축:100 mm. 지지대 외측 간격54 mm, 칼라 두 개22 mm를 포함하면76 mm이므로 양끝에 공칭12 mm씩 남는다.
- 칼라: 보어가 축보다 +0.012~+0.050 mm 크며 M4×12 클램프 체결로 고정된다.

## 모델에서 단순화하거나 아직 확인하지 않은 것

- SHAT12 주물 필릿·구배와 실제 클램프 슬릿 상세
- 프로파일 장착면 이외의 내부 공동 일부
- HNTT8 아래 테이퍼와 나사 입구 상세
- BJ761 아이-축부 연결 필릿과 실제 나사산
- PHS12L 그리스 니플, 구리 부시/소켓 내부 및 실제 나사산
- 전체 축 모델의 MCL-12-F 슬릿과 M4 체결나사 형상
- 실제 납품 폭에 따른 최종 DIN988 심 수량
- STB 압축 허용, SHAT 클램프 유지력, 프로파일 슬롯 턱의 국부 휨·미끄럼 정격

따라서 3D 모델은 **카탈로그 공칭 치수상 조립 방법과 공간 적합성**을 확인한 것이다. 실물 끼움, 체결토크, 허용하중을 확정한 결과는 아니다.

## 조립 순서

1. HNTT8-5 두 개씩을 각 슬롯에 넣는다.
2. SHAT12의 동봉 M4 클램프 나사를 잠시 제거한다.
3. M5×16 + DIN433 M5 와셔로 두 지지대를 느슨하게 장착한다.
4. 칼라-지지대-심-BJ761/PHS-심-지지대-칼라 순서로 Ø12 축을 통과시킨다.
5. 축으로 두 지지대 보어를 맞춘 뒤 M5를 체결한다.
6. SHAT12의 M4를 다시 조립하여 축을 클램프하고, 양쪽 MCL-12-F를 지지대 외측면에 붙여 체결한다.
7. 무부하/상판 별도 지지 상태에서 턴버클과 상하 관절을 연결한다.
