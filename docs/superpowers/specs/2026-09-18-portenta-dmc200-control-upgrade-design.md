# Portenta·DMC-200 기반 자동수평 제어계 개정 설계

작성일: 2026-09-18  
상태: 사용자 개념 승인 후 명세화, 개정 BOM·발주 전  
적용 대상: 카트·적재물·사람이 없는 공개형 자중 자동수평 PoC

## 1. 목적

기존 `Mega2560 + MDD10A 2대 + MPU6050` 제어계를 Arduino/C++ 개발성을 유지하는 산업용 제어계로 교체한다. 예비 액추에이터 구매로 비용을 늘리지 않고, 축별 폐루프 제어·상하부 경사 비교·실시간 표시·시험 기록 능력을 강화한다. 전체 기본 구매비는 VAT 포함 380만~400만원을 목표로 하되, 불필요한 고급화나 중복 구매는 하지 않는다.

## 2. 유지되는 요구조건

- 기구 자유도는 Z, pitch, roll이며 X, Y, yaw는 기구적으로 구속한다.
- 액추에이터는 `LM4075OE-1075`, DC 24 V, 스트로크 100 mm, 엔코더 5 V, 3대를 유지한다.
- 액추에이터 내장 종단 리미트만 사용하며 외장 리미트와 별도 기계식 스토퍼는 추가하지 않는다.
- 사용자의 START 명령 후에만 동작한다.
- 하부를 천천히 기울이는 동안 상부 수평을 유지한다.
- 사람·카트·적재물 탑재 성능이나 안전 인증을 주장하지 않는다.
- 기존 Rev E 기구 형상과 조립 인터페이스를 바꾸지 않는다.

## 3. 승인 제어 아키텍처

```text
START / STOP / E-STOP
          |
          v
Arduino Portenta Machine Control
  |-- 상부 2축 경사센서
  |-- 하부 2축 경사센서
  |-- 산업용 HMI
  |-- 시험 데이터 기록
  |
  +-- RS485 버스 -- DMC-200 A1 -- LM4075OE A1 encoder/motor
                  -- DMC-200 A2 -- LM4075OE A2 encoder/motor
                  -- DMC-200 A3 -- LM4075OE A3 encoder/motor
```

Portenta Machine Control은 수평 목표, 상하부 각도 비교, 세 축 목표위치, 운전상태, 오류 및 로그를 관리한다. DMC-200 세 대는 각각 한 축의 A/B 엔코더를 직접 읽고 위치·속도·가감속·전류제한을 수행한다. 따라서 Portenta의 전용 엔코더 입력이 2축인 제한은 문제가 되지 않는다.

## 4. 하드웨어 변경

### 삭제

- Mega2560 호환 제어보드 1대
- MDD10A 2채널 모터드라이버 2대
- MPU6050 보드 1대
- 위 부품에만 필요했던 5 V 배선·장착 부품 중 중복분

### 추가

- Arduino Portenta Machine Control `AKX00032` 1대
- Motorbank DMC-200 3대
- RS485 방식 또는 Portenta와 전기적으로 호환되는 상부·하부 2축 경사센서 각 1대
- Modbus RTU/TCP 또는 검증된 직렬 프로토콜을 지원하는 산업용 HMI 1대
- 절연 RS485 인터페이스 또는 절연 리피터 1세트
- 실드 트위스티드페어 통신선, 종단저항, 커넥터 및 DIN 레일 장착부품
- CSV 또는 동등 형식의 시험 로그 저장을 위한 저장매체
- 필요할 경우 3축 독립 변위 확인계. 단, 예산과 조립시간에 여유가 있을 때만 포함한다.

## 5. 제어 책임 분리

### Portenta

- 전원 투입 후 모든 축 정지 상태 유지
- START 입력 및 운전 모드 관리
- 상부 경사센서 기준 자동수평 오차 계산
- 하부 경사센서로 입력 기울기와 상부 보상량 기록
- 세 DMC-200에 축별 목표위치·속도 명령
- 축간 위치차, 통신시간초과, 센서 stale, 과도기울기 감시
- HMI 상태 표시와 시험 로그 생성
- STOP 또는 오류 시 세 축 정지 명령 및 기존 하드웨어 모터전원 차단계 연동

### DMC-200

- 해당 축의 5 V A/B 엔코더 입력
- 해당 축 DC 모터 양방향 구동
- 위치·속도 폐루프와 가감속
- 전류제한 및 축 상태 피드백
- RS485 명령·응답

내장 리미트는 액추에이터 내부에서 모터 종단 동작을 제한한다. 제어기는 내장 리미트의 별도 접점 상태를 직접 읽는다고 가정하지 않으며, 종단 부근에서는 엔코더 위치·무펄스·전류 및 시간초과 조건으로 추가 정지한다.

## 6. 소프트웨어 이식 범위

기존 Mega2560 펌웨어에서 다음 로직은 재사용한다.

- START 전 무동작
- HOME, JOG, LIFT, LEVEL, STOP 명령 상태기계
- pitch/roll 목표와 세 축 길이차 변환
- 5도 기울기 fault, 동작 시간초과, 센서 stale, 축간 위치차 검사
- CSV 텔레메트리 필드와 시험 순서

다음 부분은 교체한다.

- 직접 PWM·방향 출력 → DMC-200 RS485 목표 명령
- Mega 외부인터럽트 엔코더 계수 → DMC-200 위치 피드백 읽기
- MPU6050 I2C 읽기 → 선정 경사센서 프로토콜
- USB 직렬 표시 중심 → HMI 표시와 저장매체 로그 병행

Portenta용 코드는 Arduino C++ 프레임워크로 작성한다. PLC IDE와 유료 PLC 키는 사용하지 않는다.

## 7. HMI 및 기록 화면

한 화면에 다음 항목을 표시한다.

- 운전상태: IDLE, HOMING, LEVELING, HOLD, STOP, FAULT
- 상부 pitch/roll
- 하부 pitch/roll
- A1/A2/A3 현재 위치와 목표 위치
- 통신·센서·축 오류
- START, STOP, HOME 및 자동수평 시작 조작

로그에는 timestamp, 상·하부 pitch/roll, 세 축 현재·목표 위치, 상태, 오류코드를 20 Hz 이상으로 기록하는 것을 목표로 한다. 실제 센서 갱신율이 낮으면 센서의 검증된 최대 주기로 낮춘다.

## 8. 예산 구조

- 기존 Rev E 기본안: 약 149.5만원
- Portenta와 DMC-200 3대 전환: 순증 약 60만원
- 상·하부 산업용 경사센서: 약 60만~100만원
- 산업용 HMI: 약 40만~70만원
- 통신·저장·배선·전장함 장착 개선: 약 20만~30만원
- 독립 변위 검증 또는 실제 가공 견적 증가분: 잔여 예산 내 반영

최종 BOM은 VAT와 배송비를 구분하고, 확인되지 않은 계획가는 실제 장바구니 또는 견적 금액으로 교체한다. 총액을 맞추기 위한 불필요한 예비품·중복품은 넣지 않는다.

## 9. 구매 선정 기준

- 국내 카드결제 또는 국내 사업자 견적·세금계산 증빙이 가능할 것
- Portenta는 `AKX00032`, DMC-200은 Motorbank 정품으로 형번을 고정한다.
- 경사센서는 두 대가 동일 모델이며 pitch/roll, 영점 조정, 갱신율 20 Hz 이상, 디지털 통신을 지원하는 제품을 우선한다.
- HMI는 국내 재고, 24 V 전원, Modbus 지원, 최소 7인치, 화면 편집도구 제공 제품을 우선한다.
- 2026년 11월 조립·결과보고 일정 전에 입고 가능한 품목만 발주한다.
- 해외 직배송보다 국내 재고·국내 유통을 우선하되, 기능적으로 대체가 없으면 별도 표시한다.

## 10. 검증 계획

1. Portenta만 통전해 START 전 출력과 RS485 송신이 정지 상태인지 확인한다.
2. DMC-200 한 축씩 모터를 분리한 상태에서 통신·엔코더 입력을 확인한다.
3. 무부하 한 축 JOG로 극성, 위치 부호, 내장 리미트 정지와 역방향 탈출을 확인한다.
4. 세 축 HOME과 0/25/50 mm 동기 이동을 확인한다.
5. 상·하부 경사센서의 축 방향과 영점을 동일 기준면에서 대조한다.
6. 하부를 천천히 기울이며 상부 잔류각, 세 축 위치와 상태를 로그로 저장한다.
7. HMI 화면, 장치 전체, 단계별 조립 및 시험 사진을 결과보고서용으로 촬영한다.

## 11. 주요 위험과 완화

- DMC-200이 LM4075OE의 엔코더 전기형식과 직접 호환되지 않을 수 있다. 발주 전 Motorbank에 5 V A/B 6 ppr 액추에이터 모델을 명시해 서면 호환 확인을 받는다.
- RS485 명령 지연이나 세 축 순차 응답으로 동기성이 떨어질 수 있다. 동일 버스 주소를 분리하고 고정 주기 명령·응답 시간부터 벤치시험한다.
- Portenta Machine Control은 기존 Mega와 핀·라이브러리가 다르다. 기존 상태기계와 수학부를 분리해 재사용하고 하드웨어 접근부만 교체한다.
- 고급 HMI나 센서의 납기가 길 수 있다. 국내재고를 최우선으로 하고, 납기가 확인되지 않은 품목은 BOM 승인 품목으로 확정하지 않는다.
- 산업용 부품 사용이 사람 탑승이나 안전 인증을 의미하지 않는다. 공개형 자중 PoC 범위를 유지한다.

## 12. 완료 기준

- 개정 BOM 총액이 VAT 포함 380만~400만원이며 각 금액의 구매 근거가 있다.
- 예비 액추에이터는 BOM에서 제외된다.
- Portenta, DMC-200 3대, 동일 모델 경사센서 2대와 HMI의 국내 구매경로·납기·인터페이스가 확인된다.
- 회로도·단자표·배선표·I/O 맵이 새 아키텍처와 일치한다.
- 펌웨어가 Portenta 대상으로 컴파일되고, 하드웨어 없이 가능한 통신·상태기계 시험을 통과한다.
- 실제 조립 후 START 전 무동작, 축별 HOME, 동기 Z 이동과 저속 자동수평을 순서대로 확인한다.
