# 제외 범위

## 2026-09-01 수동안에서 추가 제외

- 전동 액추에이터와 모터 드라이버
- IMU·엔코더 기반 자동수평 제어
- MCU 펌웨어와 원격조작
- AC-DC 전원, 배터리, 충전기와 전장함
- 이동 중 또는 하중 운반 중 조절
- 수동 조절 구조를 자동 수평유지장치로 표현하는 것

위 항목의 마지막 검토안은 `design_basis/archived_powered_control_architecture_2026-09-01.md`에 보존한다.

## 설계하지 않는 항목

- AMR 또는 AGV 본체
- 바퀴, 캐스터, 주행 모터, 감속기, 배터리 구동부
- SLAM, 장애물 인식, 경로 계획, 자율주행
- 로봇팔
- 기존 자재운반 카트 본체 및 자재 지지 프레임
- 작업자 탑승 구조
- 고속 주행 중 동적 수평유지
- 실제 제품 선정과 공급업체 확정
- 유한요소해석, 피로수명, 낙하·충격 인증
- 상세 제작도면, 공차도, 용접도, 가공 G-code
- 임베디드 제어코드
- 현장용 고하중 인증 및 안전성 보증

## Phase 1에서 보류하는 항목

- 파라메트릭 CAD 부품/조립체
- STEP, STL, DXF, GLB 내보내기
- 복합자세 정밀 간섭검사
- 최종 액추에이터 추력·속도·듀티사이클 검증
- 최종 BOM 및 실제 견적
- 하부 이동체 전체 전도 안정성
- 상세 기계식 스토퍼와 래치 제작도

위 항목은 개념 승인 문구 `APPROVE CONCEPT` 이후 Phase 2 또는 Phase 3에서만 진행한다.
